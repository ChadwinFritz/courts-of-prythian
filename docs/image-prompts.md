# Courts of Prythian — Image Generation Prompts

Visual identity: **Candlelight on Dark Stone**
All images share a near-black warm background (`#0f0b18`), candlelit golden highlights (`#c9943a`), painterly oil-on-canvas texture, and a Tolkien-meets-dark-romance aesthetic. No harsh studio lighting; light sources are always diegetic (candles, starlight, embers, moonlight).
